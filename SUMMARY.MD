# Project Summary

This project uses Linear Regression to predict house sale prices using seven property features from the Kaggle House Prices dataset.

The model achieved an RMSE of $38,998.66 and an R² score of 0.802 on the test dataset.

The project includes model evaluation, a residual plot, sample predictions compared with actual sale prices, and a saved trained model.

An interactive Streamlit application allows users to enter property characteristics and receive a predicted house price.

The application also includes a Housing Crash Simulator where users can adjust interest rates from 3% to 8% and observe a simulated change in the predicted house price. The interest-rate effect is a demonstration assumption and was not learned from the dataset.
